# DOCUMENTAÇÃO DO PROJETO

PARA A EXECUÇÃO, NO BASH DIGITE:
>> ./calculadora.sh
O arquivo shell irá executar calculadora

EXPLICAÇÃO DO CÓDIGO DO ARQUIVO calculadora.py:

1. O código solicita ao usuário para entrar o primeiro valor, o segundo, escolher uma operação ou pressionar espaço para interromper a calculadora
2. enquanto não é pressionado o espaço a calculadora inicia novamente após o resultado da operação anterior ser exibido
